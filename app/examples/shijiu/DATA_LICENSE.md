# Shijiu Lake example data

The three GeoJSON layers are derived from OpenStreetMap and are provided under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Attribution: **© OpenStreetMap contributors**, with [copyright and license information](https://www.openstreetmap.org/copyright).

This English edition changes names and descriptive attributes, while preserving every geometry coordinate and OSM object ID. Proper names are rendered in pinyin with English feature-type words. These are working translations, not a claim of officially certified English names. Duplicate original-language tags and per-edit usernames/user IDs are omitted. Source object URLs, edit versions, timestamps and aggregate attribution remain.

`source_sha256` in `sources.json` identifies the historical original snapshot. `working_sha256` identifies the translated file included here. Original development input files and some historical check documents are not bundled; paths describing them are labels in the provenance record, not promised local files.

The source records document known limitations, including unknown survey dates, the collaborative status of administrative boundaries and incomplete historical retrieval metadata for the full river network. This dataset does not establish surveyed water levels, statutory management limits, official administrative delineation or verified flow direction.
